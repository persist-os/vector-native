# Vector-Native Prompts

This directory has different sample prompts for Vector Native for different use cases.

The goal is to have a set of prompts that are easy to understand and use, and are well-documented.

Current prompts:
- [hybrid_quotes_vn.md](hybrid_quotes_vn.md): A prompt for translating English prose into Vector Native Hybrid Syntax.
- [a2a_notes_hybrid.yaml](a2a_notes_hybrid.yaml): A prompt for writing A2A notes in Vector Native Hybrid Syntax.
